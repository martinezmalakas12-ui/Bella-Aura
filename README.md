# Bella Aura Cosmetics 

## Descripción del proyecto
Bella Aura Cosmetics es un sistema de gestión empresarial desarrollado como proyecto propio.
Permite administrar visitantes,  trabajadores y  proveedores  mediante  registros digitales.

## Propósito
Organizar los registros de la empresa, asignando identificadores independientes  para  cada
categoría y permitiendo gestionar su información y actividad.

## Categorías
- Visitantes
- Trabajadores
- Proveedores

Cada categoría tiene su propio contador de IDs para evitar  confusiones entre los registros.

## Operaciones del sistema
- Inicializar    el    sistema   y    su  administrador.
- Crear   visitantes,   trabajadores   y    proveedores.
- Asignar IDs consecutivos independientes por categoría.
- Modificar los datos de los registros.
- Registrar actividad asociada.
- Dar de baja registros que no tengan actividad.
- Validar permisos administrativos.

## Tecnología utilizada
- Rust
- Anchor Framework
- GitHub
